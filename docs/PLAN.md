# 轻读 Reading Cues：实现计划

日期：2026-10-20。目标平台：桌面 Chrome / Edge（Manifest V3）。

## 本轮目标

交付一个可以本地安装的原子插件：用少量、可撤销的视觉提示，帮助读者注意中文正文里的完整条件、限制、转折表达。发布源代码、离线安装包、维护规范和实际验证结果到 GitHub。

不调用模型、不收集阅读内容、不要求账户。这里的“提示”只表示规则命中，不表示程序判定了重点、事实或语义范围。对中文 ADHD / 阅读障碍人群的实际帮助仍需使用者验证。

## 从聊天记录得到的约束

1. 默认小词库直接可用；个人词库可以添加、忽略、移除和导出。
2. 完整表达优先；不将单字“不”解释成否定；歧义时保守跳过。
3. 成对表达在同一句、有限距离内匹配；两个片段一起保留或一起省略。
4. 提示稀疏、每段有上限；分类用于规则开关，不要求学习颜色含义。
5. 保留网页的字体、文字颜色、布局、复制结果、交互与作者已有强调。
6. 逐站点主动启用；一键暂停；只用浏览器本地存储。

## 架构与选择

- 词库：原创 JSON，稳定 ID、简繁词形、类别、优先级、配对规则、排除规则、原创正反例、来源类型。
- 纯函数匹配器：最长词形和完整配对先竞争；排除覆盖；重叠消解；段落提示预算；用户选择优先。输入和输出均可独立测试。
- 渲染器：CSS Custom Highlight API + Range，不包裹网页文字。跨行内节点匹配；编辑区、代码、导航、隐藏内容、已有强调和交互控件形成边界。
- 初版样式：浅底色 / 下划线。`::highlight()` 不能修改字重，所以将“轻加粗”留给独立原型，避免为模拟加粗而修改网页节点。
- 扩展：可选站点权限；按授权站点注册内容脚本；本地保存设置与个人词；选中文字后右键添加。
- 本地试读页：可比较原文与两种样式，查看可解释的规则命中，用于验证兼容与个人体验。
- 工具链：运行时无第三方依赖。Node 内置测试和打包；Playwright 仅用于开发验证。

## 迭代顺序和验收

1. 研究与边界：核对一手论文、无障碍指南、浏览器规范与资源许可，记录适用范围。
2. 语言内核：词库和匹配测试。包括“不但”“差点没”、完整配对、简繁、重叠、跨句、忽略词条、密度限制、恶意导入。
3. 网页渲染：真实 Chromium 验证文本/节点/复制不变、跨节点、动态新增与移除、暗色、编辑区排除、暂停清理。
4. 扩展闭环：真实加载 MV3 扩展，验证权限、启用、刷新自动生效、个人词库、设置同步、停用、权限撤回。
5. 优化：针对实测发现修正，检查长文处理耗时与内存边界，重复受影响检查。
6. 开源：MIT、隐私说明、贡献指南、误标模板、CI、可安装 ZIP、发布说明。核对提交清单后发布。

## 本轮完成后的反馈循环

先固定样式验证“标什么”，再固定规则比较“如何标”。使用不同且难度接近的文章，轮换先后次序。记录理解（包括未提示信息）、阅读负担、漏读和继续读下去的意愿。速度只作次要记录。每条新增规则必须有正例、反例和可追踪的理由。自动测试通过不等于辅助效果得到验证。

阅读尺、朗读、整页分词、自动推断困难词、语义解释和远程词库更新不进入本轮。
