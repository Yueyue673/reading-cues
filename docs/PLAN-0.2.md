# v0.2：默认自动、扩大覆盖

日期：2026-10-20。

## 反馈与产品行为

首版只有 18 条规则，普通阅读中的线索过少；逐站启用又增加了阅读前的操作。此次直接改为：安装并完成浏览器授权后，普通网页自动处理。个人词库和设置是可选调整，暂停入口仅在用户需要时打开。

页面不增加控件、浮窗、提醒音；保持文字节点、布局和复制。全局自动仍保留用户控制，可以暂停当前网站或全部。

## 实现

1. 静态全局内容脚本，普通 HTTP / HTTPS iframe 同步自动工作。安装时也尝试处理已有标签页。
2. 白名单改为可选暂停例外；旧数据迁移保留个人词库、忽略词、样式和显式全局暂停。
3. 原创词库扩大到 374 条规则：341 条字面词条、20 条配对、13 条上下文 / 数值模式；9 类默认启用。
4. 自动密度随段落长度增长，保留完整表达和数值，词形冲突优先保留完整短语，提示尽量分布到段落不同位置。
5. 动态变化时保留仍有效的 Range；失效配对整体移除；暂停时停止正文观察与扫描。

## 验证与交付

- 逐条正反例，另外建立独立原创语段回归集，避免只在自己的词条例句上检查。
- 必须证明不打开插件 UI、不点击启用，两个不同站点自动出现提示。
- 检查跨域 HTTP 嵌入页、顶层暂停传播、另一站点继续运行、全局暂停与恢复、刷新自动生效。
- 保留原文 / 选区 / 排版和严格 CSP 检查；加入长数字输入的性能检查。
- 更新隐私、安装、升级与授权说明，打包发布 v0.2.0；公开源码与独立 CI 结果。

覆盖回归和工程性能与读者的实际辅助效果分别记录，不用规则数量替代体验反馈。
