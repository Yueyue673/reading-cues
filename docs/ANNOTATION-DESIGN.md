# 从 31 个标注片段到结构候选

日期：2026-10-20。这里记录的是一位使用者的偏好校准，不是普遍的中文关键词标准，也不是阅读效果研究。

v0.5 的附着否定、数字边界修正和直接标注工具见 [本轮迭代](ITERATION-0.5.md)；下面的 31 处参考和严格校准表保持不变。

## 从标注中推导的假设

三段原创文字分别涉及日常叙述、操作说明与科普。使用者共标了 31 个片段，覆盖原文字符约 47.5%、57.3%、51.1%。这些比例包含标点作分母，只用于描述本次材料。

| 观察 | 示例 | 候选规则 |
| --- | --- | --- |
| 时间修饰与界限属于同一块 | 周末早上、当天上午十点前、提前一天申请 | 合并时间单位与界限，允许时间修饰动作 |
| 对象可以带数量或前置修饰 | 几盆植物、介绍城市建筑的画册 | 数量＋对象、有限长度的“修饰语＋的＋名词” |
| 动作或状态比单独连接词更常被选中 | 吸收水分、保持稳定、适应能力不同 | 动宾、动词＋状态、主体＋变化谓语候选 |
| 否定和情态往往需要带着后面的动作 | 不收取费用、因此难以正常生长 | 保护否定 / 情态前缀，不只留下内部肯定片段 |
| 短词仍有价值 | 城南、整理、吸引、取消、叶片 | 不设“只有长词才重要”的规则；保留短实体和动作 |
| 不是所有名词、动词都应标 | 原文中的店主、窗边等没有被选择 | 结构候选与显示数量分离，不标满全文 |

这些是可修改的推断。31 个片段不足以确定个人稳定偏好，更不能代表所有 ADHD / 阅读障碍读者。

## 本地候选算法

1. **词性提示而非关键词白名单。** 使用 MIT 授权的 jieba 词典精简集，在本地进行词频路径分词。词性仅是词典的静态提示，会有歧义。数据来源见 [POS-SOURCE](POS-SOURCE.md)。
2. **有限结构组合。** 生成时间、数量名词组、修饰结构、动宾、位置＋动作、状态与变化谓语候选。不跨标点、空白、网页排除区域或影子树边界。
3. **边界检查。** 自动片段最多 18 个 UTF-16 单元，不以“将自动”“又买了一本”等未完成修饰、量词或引导成分结尾。个人词组按用户指定边界保留。规则不能完整解析所有句法或否定范围。
4. **冲突与疏密。** 更完整的构式优先于其零碎子词；忽略词优先。轻量 / 均衡 / 较多约为 36% / 52% / 66% 的字符预算，不是已验证的最佳参数。不能为了凑满预算切断一个片段。
5. **呈现独立。** 默认下划线。稳定多色、底色、描边式加重可选；换色不改选词或数量。同一片段同一种颜色，除非使用者主动换一组。

词性初始化分批让出执行；没有模型推理、运行时联网或行为学习。对词性歧义、人名地名、繁体、口语和复杂从句仍会误选。界面明确标为“意义块（试验）”，保留旧算法供对照。

## 严格边界的校准比较

匹配要求起止位置完全相同，既不是包含关系，也不对近似片段放宽计分。运行 `node scripts/evaluate-annotations.mjs` 可重现，详细结果输出在忽略目录 `artifacts/`。

| 方案 | 生成片段 | 与 31 个标注完全一致 |
| --- | ---: | ---: |
| 旧版逐词交替 | 45 | 4 |
| 新候选：轻量 | 16 | 15 |
| 新候选：均衡 | 29 | 24 |
| 新候选：较多 | 38 | 27 |

**这些材料参与过规则调整，结果只是校准拟合，不能写成新文章准确率、阅读速度或理解提升。** 密度较高虽多覆盖了几个目标，也生成更多额外片段。没有根据这张表宣称已经找到最佳方案。

原标注“不需要重新”原样保存；候选倾向扩成“不需要重新提交申请”，因此严格比较时仍算边界不一致。该差异需要使用者在对照页继续确认，不替使用者修改原始参考。

## 下一轮验证

离线 `compare.html` 可对同一段切换原文、旧分词、新候选、使用者原标注；另含社区通知、出行、科学解释与视频评论四段新文字。新段没有使用者标注，不计算伪准确率。它们也不再被称为“未参与开发的盲测集”：边界缺陷检查已经使用过这些材料。

同文切换适合观察差异；理解比较应使用不同但难度相近的文章、轮换顺序，检查未标信息。下一轮主要收集：哪些边界别扭、哪些多余、哪些应合并，以及读完整段后的理解和负担。工程回归与实际辅助效果继续分开。
