# 轻读的对外介绍与视觉

核心创意是“句子里的路标”：浅色词组标记像路标，帮助读者辨认自己想一起读的几个字。这是对功能的比喻，不表示程序能找出文章重点，也不承诺阅读或健康效果。

## 文案与阅读顺序

项目先说明是什么、能做什么、怎样开始、需要什么条件，再给实际案例。面向普通读者，用“标记多少”“添加常漏看的词”等动作，避免用内部算法名称代替介绍。

README 的顺序是：介绍与入口、概念封面、真实案例、常用调整、安装、范围与限制、贡献。详细操作在[使用说明](GETTING-STARTED.zh-CN.md)，开发命令在[开发说明](DEVELOPMENT.md)，海报在[独立页面](POSTERS.md)。英文版本同步涉及的事实和入口。

结构参考 [Voyager](https://github.com/voyager-crew/voyager) 的项目入口、分组介绍、产品展示与安装顺序。没有使用其标志、插画、截图或文案。

## 视觉分工

暖白纸面、深绿文字、浅彩书签，与轻读现有标志和界面衔接。纸雕插画表现阅读、路标和个人记号；实际功能仍由截图说明。

| 素材 | 用途与来源 |
| --- | --- |
| `artwork/route.png` | 图片生成模型制作的纸带路线、公交车和旧书店，呼应示例短句 |
| `artwork/focus.png` | 图片生成模型制作的台灯与书页，作为段落聚焦的概念比喻 |
| `artwork/personal.png` | 图片生成模型制作的金色书签，表现个人选择的词语 |
| `artwork/start.png` | 图片生成模型制作的书页与入口，作为开始使用的概念插画 |
| `assets/hero-zh.jpg`、`hero-en.jpg` | 概念插画与精确排版组合，1600 × 900 的横向 README 封面，以 JPEG 减少首页加载量 |
| `assets/cover.png`、`case-personal.png`、`case-aids.png` | 实际扩展运行截图，经排版形成案例图，不能用生成图替换其中结果 |
| `posters/01-phrase.png` 至 `04-install.png` | 四张独立的 2160 × 2700 海报；分别介绍用途、场景、个人词语与安装 |
| `posters/previews/` | 海报页面使用的轻量预览，点击后打开独立高清 PNG |

插画使用 **内置 image_gen 工具**生成。完整原始提示词及素材对应关系在 [prompts.json](artwork/prompts.json)。后三张以第一张作为风格参考，使用图片生成模型分别创作；没有调用收费 API 脚本或把生成模型加入插件。

## 准确与维护

- 模型生成的插画不包含文字或软件界面；中文、英文、网址和步骤由版式文件排版。
- Logo 保留现有设计。实际界面不换字、不增加按钮、不重画标记，不改变截图的宽高比例。
- 对照采用同一段文字和相同显示条件。自动选词错误不通过修图隐藏。
- 概念插画标明用途，不冒充真实截图。病例、用户数量、效果百分比和虚构评价不作为装饰。
- README 使用横向封面和少量案例；不把四张宣传海报全部插入首页。
- 生成后逐张查看原图和 360 × 450 的手机尺寸图，检查文本遮挡、留白和入口。二维码从最终完整海报解码核对。
- 宣传插画在仓库中保存，不进入扩展安装包，不成为网页阅读功能的联网依赖。

编辑源文件是 [hero.html](artwork/hero.html)、[posters.html](posters/posters.html) 和 [posters.css](posters/posters.css)。导出命令见[开发说明](DEVELOPMENT.md)。模型素材再次生成可能不同；已选定的图片随仓库保存，日常修改文案与排版无需再次调用模型。

海报、版式及本项目提供的宣传素材按项目 [MIT](../LICENSE) 许可提供；未包含第三方标志或参考项目的艺术素材。用户网页文字、私人词库和浏览记录没有用于生成插画。
