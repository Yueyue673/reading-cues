# v0.6.1

首页现在先展示同一份通知的标记前后，再说明怎样添加“截止时间”、开启阅读尺或突出一段。三组案例都由实际扩展操作截图生成，可以按文档中的步骤复现。

设置里的“意义块密度”改成“标记多少”，“意义块”改成“自动标记词组”。修正了插件介绍仍写“默认下划线”的旧说明；默认仍为最浅一档的随机彩色底色。选词规则和已有设置保持不变。

下载安装 `reading-cues-0.6.1.zip`，完整解压，在 Chrome / Edge 的扩展管理页加载。更新时覆盖原目录、重新加载扩展，再刷新网页。

案例展示功能如何运行，不代表已经证明阅读理解或专注力改善。安卓、Firefox、Safari 尚未适配。
