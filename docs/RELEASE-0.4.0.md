# 轻读 v0.4.0 · 标注驱动的意义块候选与评论支持

- **按使用者标注重做选词候选**：时间、修饰语、动作、状态尝试整体保留，减少逐词交替的零碎标记。三档密度，旧分词和逻辑提示仍可切换。新算法明确标为试验。
- **离线对照页**：固定下划线，切换原文、旧算法、新候选和使用者原始标注；还有四段新题材文字与纯文字粘贴入口。未宣称已找到最佳算法。
- **默认下划线**：新增描边式加重、加重＋下划线；加重保留字形尺寸与换行，不是更换字体的字重。
- **可选稳定多色**：同一词组保持同色，滚动和重扫不换色。主动“换一组”才重新分配，不增加标记数量。
- **支持嵌套开放评论组件**：补上开放 Shadow DOM 的扫描、样式、动态回复、延迟出现与清理。已在一个公开 B 站视频页使用实际扩展验证评论 / 楼中楼有标记，输入框无标记。
- **继续本地运行**：内置 MIT 授权词性词典精简集，运行时不联网、不调用模型、不收集阅读行为，无新增权限。

校准的三段共有 31 个标注：旧算法 4 个边界完全一致，新候选均衡档为 24 个。**这些样例参与了调规则，不代表新文章准确率或阅读效果。**

## 安装 / 更新

完整解压 `reading-cues-0.4.0.zip`。已有解压安装：覆盖原目录 → 扩展管理页“重新加载” → 刷新文章页。首次安装在 Chrome / Edge 扩展管理页开启开发者模式，加载含 `manifest.json` 的目录。

升级保留个人词库、忽略词、样式与暂停设置；原逐词模式迁移到新候选，可在弹窗切回。新安装默认下划线，已保存的样式继续保留。手动安装不会自动更新。包内双击 `compare.html` 即可离线比较，不需安装。

当前主要面向简体中文。关闭的影子树、PDF、图片文字和浏览器保护页未支持。开放评论兼容不等于所有网站都已验证。
