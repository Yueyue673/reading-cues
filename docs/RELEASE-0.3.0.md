# 轻读 v0.3.0 · 稳定标记、词组分界与自由配色

回应滚动 / 鼠标 / 视频时闪烁、选词方向与颜色不清楚的反馈。

- **修复清空重画的闪烁路径**：保留未变化的高亮和范围；小段新增局部处理；样式更新独立合并，滚动中延后扫描。真实视频播放、鼠标移动、播放器动态控件与滚动均加入回归测试。
- **默认词组分界**：浏览器本地分词，交替标记多字词与完整表达，帮助辨认边界，不把颜色当作重要程度。可调密度，个人词组优先纠正；原来的逻辑 / 数值提示和仅个人词库可选。
- **颜色更清楚**：默认底色强度 50%，可调 20–85%；六组预设、浅 / 深网页独立自由取色。必要时自动配深浅文字色，图片背景采用清楚的下划线。
- **仍然全局自动、本地运行**：没有新增权限、模型调用、遥测或正文上传。
- **重新复核设计依据**：记录中文分词、视觉线索、走神和理解监控的研究及相反结果。自动分词可能出错，功能通过测试不等于辅助效果已验证。

## 更新方式

下载并完整解压 `reading-cues-0.3.0.zip`。已有解压安装用户：可先备份个人词库，用新包覆盖原目录，在扩展管理页点击**重新加载**，再刷新文章页。

v0.2 的个人词库、忽略、样式、暂停和站点列表保留，默认方式改成“词组分界”。手动安装不会自动更新。首次安装仍在 Chrome / Edge 的扩展管理页开启开发者模式并加载解压目录。安卓尚未适配。

本地 1,035 项核心 / 语言 / 后台检查与 20 组真实浏览器回归通过，包括视频帧实际推进、正文截图一致、自定义颜色与严格 CSP。不同网站、显卡和长时间阅读仍需实际反馈。
