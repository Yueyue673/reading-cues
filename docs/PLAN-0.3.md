# v0.3：边界、稳定性与清晰度

使用反馈：全部网页滑动不顺、鼠标移动及视频播放出现闪烁；连接词选词方向偏离需要；底色不够清楚。使用者选择默认“完整词组与概念，帮助看清边界”。

## 验收目标

- 安装后仍全局自动。默认本地词组分界，逻辑提示和仅个人词组可选。
- 不再在样式变化时清空全部标记；保留未变的 Highlight 与 Range。
- 小段新增只处理新增块；鼠标 / 媒体样式与实际文本编辑分队列，防止持续重算整页。
- 真实视频帧与鼠标、滚动、播放器控件同时变化时，正文标记不清空，静态正文截图一致。
- 自由选择浅 / 深页面颜色、六组预设、20–85% 底色强度，默认 50%。文字对比度保护与强制颜色模式保留。
- v0.1 / v0.2 升级保留词库、忽略、样式、显式暂停、暂停站点；不增加权限。

## 研究约束

见 [研究复核](RESEARCH-REVIEW-0.3.md)。不要用规则数、标记数、测试数、注视位置变化代替阅读效益。词界错误会干扰；底色不是解决所有中文阅读 / ADHD 困难的方法。当前改动是明确偏好驱动的可用方案，辅助效果待验证。
