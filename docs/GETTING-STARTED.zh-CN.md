# 开始使用轻读

轻读在中文网页上给部分词组加浅色标记，也能提示你自己添加的词。需要电脑上的 Chrome / Edge；手机、Firefox 和 Safari 暂未适配。[English](GETTING-STARTED.en.md)

## 安装

1. 打开[下载页](https://github.com/Yueyue673/reading-cues/releases/latest)，在附件中下载 `reading-cues-0.6.1.zip`，不要选 GitHub 自动提供的源代码包。
2. 完整解压到一个以后不会随意删除或移动的文件夹。
3. 在 Chrome 地址栏输入 `chrome://extensions`，或在 Edge 输入 `edge://extensions`。开启“开发者模式”。
4. 点“加载已解压的扩展程序”，选择包含 `manifest.json` 的文件夹。
5. 确认允许访问网站。刷新已经打开的网页，普通网页就会自动标记。

不需要每个网站单独开启。浏览器中手动限制的网站访问权限仍然优先。

## 找到设置

在浏览器右上角的扩展菜单中找到“轻读”，打开它。常用显示设置在这里；“个人词库与设置”可以添加词语和管理暂停的网站。

默认是浅彩色底色，强度为 20%。同一个词组保持同色，滚动不会重新换色。想换配色时，点“换一组颜色”。

![同一份通知，左边是原文，右边是默认自动标记；文字、字号和换行相同。](assets/cover.png)

## 只提示自己常漏看的词

例如，只想提示通知中的“截止时间”：

1. 打开“个人词库与设置”。
2. 把“标记哪些词”改为“只提示个人词库”。
3. 在“我需要提示”中输入 `截止时间`，点“添加”。
4. 回到网页，文字完全相同的位置就会有提示。

![实际设置与结果：添加“截止时间”后，同一通知中两次出现都被标出。](assets/case-personal.png)

想保留自动标记，可以选择“自动标记词组（默认）”；个人词语也会一起生效。也可以选中网页文字，右键添加。词语必须是 2–40 个字符，按原样匹配，不会自动扩展近义词。

不想再提示某个词，把它加入“这些表达不再提示”。从“我需要提示”移除一个词，只是删除自己的添加；自动规则仍可能选择它。

## 调整颜色、样式和数量

- 太浅：展开“颜色与强度”，调高“底色强度”。
- 太花：把“配色方式”改为“单色”，再选喜欢的颜色。
- 太密：把“标记多少”改为“少一些”。
- 喜欢线条：选择“下划线”；也可以选择“加重”或“加重＋下划线”。
- 想回到默认配色：点“使用最浅的随机多色”。

单色的自由取色在多色模式下会变灰。颜色不表示重要程度；轻读不能可靠判断文章重点。

## 定位当前行，或突出当前段落

在“更多阅读辅助”中选择：

- **阅读尺**：一条横带跟随鼠标，帮助定位正在看的行。
- **段落聚焦**：鼠标所在段落保持原样，周围区域变暗。

![同一份通知、同一鼠标位置：左边是阅读尺，右边是段落聚焦，均来自实际扩展。](assets/case-aids.png)

两项默认关闭，一次使用一种。选择“关闭”即可恢复。需要鼠标定位，不会记录鼠标移动轨迹。

## 暂停、更新和备份

只想在当前网站关闭，点“仅暂停这个网站”。想全部关闭，勾选“暂停所有网站的提示”。可以在同一位置恢复。

手动安装不会自动更新。下载新包后覆盖原目录，在扩展管理页重新加载，再刷新网页。使用相同的安装目录，可以保留原有设置和个人词库。

在“个人词库与设置”底部可以导出词库。备份包含“我需要提示”和“不再提示”，不包含网站权限。导入会合并、去重，不会清空已有词语。

## 不安装，先试一段

双击解压目录里的 `demo.html`，可以粘贴文字、试颜色和样式。这里的输入不保存，刷新会清除。

打开 `compare.html`，可以选“自己标注”，拖选想一起读的词组并点“标记”。完成后，对照自动标记与自己的选择。

![工作台完成标注后，左右对照自动结果和自己的标记。](assets/comparison.png)

可以撤销、继续修改、复制或导出。标注仅在当前页暂存，刷新前请保存；不会自动加入插件个人词库。

## 没有显示或标得不合适

先检查轻读是否被暂停、浏览器是否允许访问这个网站，再刷新页面。也检查是否选了“只提示个人词库”，而页面没有这些词。

PDF、图片文字、浏览器设置页和部分封闭网页组件不支持。网页评论区的结构不同，不能保证每个页面都兼容。

自动标记仍可能分错，复杂句、人名和繁体内容尤其如此。可以添加完整词组、减少数量或关闭；不是所有人都会觉得有帮助。
