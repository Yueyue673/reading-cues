# 轻读 v0.2.0 · 默认全局自动，扩大词库覆盖

本次改动直接回应首版需要逐站开启、覆盖不足的问题。

- **安装后自动工作**：普通 HTTP / HTTPS 页面默认自动提示，不需要打开插件，也不需要逐站授权。页面没有新增按钮、浮窗或提示音。
- **18 → 374 条原创规则**：341 条字面词条（568 种词形）、20 条配对规则（32 种形式）、13 条上下文 / 数值模式。
- **9 类默认覆盖**：限制、条件、转折、因果、递进、顺序与时间、解释与举例、完整数值、完整概念。
- **自动提示数量**：根据段落长度分配，长段落不再固定最多两组。完整表达优先，减少重复概念，保留未提示文字的正常可读性。
- **嵌入页也自动**：支持普通 HTTP / HTTPS iframe；暂停顶层网站会同时暂停其中的嵌入正文。
- **安静更新**：动态追加内容时保留有效提示，避免整页反复清空。仍可随时暂停一个网站或全部网站。
- **本地处理**：没有模型调用、阅读内容上传或统计追踪。

## 安装与升级

下载并完整解压 `reading-cues-0.2.0.zip`，在 Chrome / Edge 扩展管理页加载包含 `manifest.json` 的目录。

已有 v0.1 可先备份个人词库，再用新包覆盖原安装目录并重新加载。新版增加全局网站访问，浏览器可能要求确认权限或重新启用扩展；完成这一次授权后就不需要逐站开启。刷新已打开的文章页即可。

同一安装目录升级会保留个人词库、忽略词和样式，旧白名单迁移为全局自动；显式全局暂停保留。尚未上架扩展商店，手动加载包不会自行更新。

该版本仍主要针对中文正文，不处理 Shadow DOM、PDF、图片文字和浏览器保护页。扩大覆盖与工程测试通过不等于阅读辅助效果已经得到验证。
