# 轻读 v0.5.0 · 更完整的边界与直接标注

- 修正否定形容词与情态动作，减少把“并不稳定”标成“稳定”等片段。
- 常见数字、单位、日期与时刻一起保留；区分“降低了20元”和“降低到20元”，范围后半不误作负数。
- 减少“没有”“才能”“不意味着完全”等未完成候选；有限短否定分句保留补足部分。
- 对照页新增“我来标注”：选取、撤销、移除、确认完成，复制本段或导出全部 JSON。重复词的位置分别记录，草稿与确认状态区分。
- 对照页可比较三档密度；标注按钮在窄屏滚动时保持可见。新增否定、数值和日期边界检查文字。
