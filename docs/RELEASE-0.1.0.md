# 轻读 v0.1.0 · 首个试用版

一个本地运行的中文阅读提示插件，从少量完整表达开始。MIT 开源，无模型调用、无统计追踪。

- 18 条原创规则，覆盖限制、不确定性、成对条件和转折。
- 浅底色 / 下划线，保留原文、换行、复制和网页文字节点。
- 按站点启用；个人词库、忽略、右键添加与 JSON 备份。
- 可随时暂停；动态页面、亮暗背景、处理上限与严格网页样式限制的兼容检查。
- 附可离线打开的 `demo.html`、研究依据、隐私说明、贡献规范和验证记录。

下载 `reading-cues-0.1.0.zip`，完整解压，然后在 Chrome / Edge 的扩展管理页开启开发者模式，加载包含 `manifest.json` 的目录。再到普通网页点击轻读启用当前网站。尚未发布到扩展商店。

这是试验性辅助工具，对中文 ADHD / 阅读障碍使用者的效果尚未验证。初版不处理 iframe、Shadow DOM、PDF 或图片文字。原生授权弹窗与真实长期阅读仍需手工试用。请用原创短句反馈误标，避免公开私人内容。
