# v0.6.0

工作台重新排版：素材放到侧栏，正文居中；常用操作分为原文、自动标记和自己标注。标完后直接显示两份读法，点“继续修改”即可回到编辑。选词时能看到当前选区，支持撤销和键盘快捷键，自己的文字通过粘贴窗口载入。

新安装默认使用最浅一档的稳定多色底色，强度为 20%。同一词组保持同色，滚动时不重新随机。原有显示设置保留；已有用户可在设置中点“使用最浅的随机多色”切换。

新增两个默认关闭的辅助：阅读尺用浅横带帮助定位，段落聚焦弱化周围区域。设置、试读页和工作台均可选择。关闭或暂停插件会移除辅助层；它们不记录鼠标轨迹。

GitHub 首页改为产品介绍、真实画面、安装和使用范围；补充英文入口、品牌封面和可复现截图脚本。文档写法统一放到 [贡献说明](https://github.com/Yueyue673/reading-cues/blob/main/CONTRIBUTING.md#文档和更新说明)。

验证：1,050 项核心检查和 30 组浏览器检查通过，包括双栏标注位置、选区与撤销、辅助层的点击穿透、严格 CSP、指针更新不重复扫描、全局暂停与清理。没有据此宣称 ADHD 或阅读困难的辅助效果。

更新：完整解压 `reading-cues-0.6.0.zip` 覆盖原目录，在扩展管理页重新加载，再刷新文章。没有新增权限；个人词库与暂停设置保留。
