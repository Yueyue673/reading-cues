# 从语言加工到阅读负担：v0.3 设计复核

核对日期：2026-10-20。起因是使用者指出：标记闪烁、选词偏向少数逻辑词、颜色看不清，并明确更需要“完整词组与概念，帮助看清边界”。这份复核把研究观察、产品推断和仍待检验的问题分开记录。

## 我们实际要减轻什么

阅读可以在不同环节费力：辨认字形，把连续汉字切成词，提取词义，把条件与指代接回句子，在跨句阅读中保持目标，以及走神后重新接上。它们可能同时出现，但不是同一个困难。“多标一些词”不能逐一解决这些问题。

中文儿童的纵向研究比较了形态意识、语音意识与快速命名等多种能力；阅读困难涉及的语言加工不止视觉形式。这是小样本儿童结果，不能替成年使用者确定困难来源。[Tong 等，2017](https://pubmed.ncbi.nlm.nih.gov/28744953/)

视觉注意广度训练研究区分了注意广度受损与完整的中文阅读障碍儿童；训练收益并非在所有组同样出现。它研究的是训练任务，并不证明网页着色具有相同作用。这一差异支持按具体困难设计功能，而不是把诊断绑定到一种界面。[视觉注意广度训练，2019](https://pubmed.ncbi.nlm.nih.gov/31831849/)

## 证据支持到哪里

| 研究 | 实际观察 | 对本项目的约束 |
| --- | --- | --- |
| [Bai 等，2008](https://pmc.ncbi.nlm.nih.gov/articles/PMC2662925/) | 熟练中文大学生阅读中，正确词界的灰色高亮没有显著快于普通文本；单字和非词分组会干扰。词界预筛得到较高的一致性。 | 不能将任意机器分组等同于实验中预先核对的词界，也不能承诺速度提升。 |
| [Zhou 等，2018](https://pubmed.ncbi.nlm.nih.gov/29435825/) | 正确交替文字颜色影响眼跳落点，错误分组产生不同落点。 | 词界可能参与眼动引导，但落点改变不能单独作为理解改善。 |
| [Ma 等，2019](https://pubmed.ncbi.nlm.nih.gov/31002292/) | 三个实验中，灰色高亮和红色提示未改善整体阅读，反而增加注视和眼跳、减慢阅读；空格对局部词识别的效果与整体速度不同。 | 必须记录负面结果，允许减少提示；更显眼不是效益指标。 |
| [中文阅读障碍儿童的间距实验，2019](https://jps.ecnu.edu.cn/EN/Y2019/V42/I4/834) | 11 位阅读障碍儿童与两组对照；字或词间距在阅读障碍组有收益，错误非词分组有代价。 | 样本很小，研究的是间距而非底色。字距原型应独立验证，不能声称当前高亮已减轻视觉拥挤。 |
| [简体中文成人实验，2024](https://pubmed.ncbi.nlm.nih.gov/39375300/) | 简体中文年轻与年长成人在正确交替文字颜色下，部分阅读与眼动指标受益；错误分组带来干扰。 | 值得尝试正确边界，但不同人群和显示方式的效果仍需验证。 |
| [繁体中文年长读者实验，2026](https://pubmed.ncbi.nlm.nih.gov/41811571/) | 76 位读者中，非词分组稳定干扰；正确词界收益受阅读能力与分词一致性影响，并非普遍获益。 | 低歧义、可纠正比扩大数量更重要。不能把长词自动等同于正确概念。 |
| [Rello 等，2014](https://aclanthology.org/W14-1204/) | 西班牙语短新闻的语义主要信息加粗，提高阅读障碍组理解，未显著提高速度。 | 它没有测试固定中文连接词、任意分词或彩色底色；旧设计把“完整表达”和“语义关键词”混得太近。 |

这些实验的人群、语言、材料长度、颜色位置和任务不同，不宜合并成一个“高亮有效”的结论。本插件使用底色，部分正面研究使用交替文字色；它们也不能视为相同干预。

## ADHD：持续接住意思与更显眼是不同目标

成人 ADHD 自然阅读的眼动研究发现，反复重读较多，一些首次阅读对词长的敏感度较低；研究将其解释为不专注阅读的相关表现。它没有证明重读都不好，也没有验证着色能解决这些表现。[Stern 等，2024](https://pubmed.ncbi.nlm.nih.gov/38327026/)

210 位成人参与的数字阅读研究比较了分阶段元认知支持与对照：额外的阅读阶段指导与理解、走神差异有关。它提供了值得做独立原型的方向：阅读目标、段落后的自我复述、回到阅读的位置提示。它不是为高亮、自动摘要或强制弹出测验背书。[Metacognitive scaffolding，2025](https://www.sciencedirect.com/science/article/pii/S0959475224001786)

视觉拥挤实验也提醒我们区分感知干扰与空间注意：部分成人 ADHD 在拥挤显示中更受干扰，但校正个体感知差异后，空间注意效应可以相当。该实验不是自然阅读，不能据此诊断个人或直接规定网页配色。[Stevens 等，2012](https://pubmed.ncbi.nlm.nih.gov/22433515/)

**产品推断：先减少插件自己引入的变化，再提供稳定、可辨认、可退出的线索。** 不闪烁是基本要求，不是“训练注意力”。保留正常回看、不自动翻页、不根据停留或鼠标推断能力，也不给阅读过程持续加任务。

## 本次如何落实

1. **边界与重要性分开。** 默认采用本地词组分界；原来的 374 条逻辑、数值与概念规则保留在可选模式。分界颜色没有语义等级，既不判断重要段落，也不推断全部否定范围。
2. **减少零碎提示。** 初始只在 2 字以上词语间交替标记，提供隔 1 / 2 / 3 组的密度选择。连续表达可合并；个人词组优先纠正。忽略仍覆盖所有模式。这些参数是工程选择，不是实验确定的最优值。
3. **承认自动分词会错。** 使用浏览器的 [Intl.Segmenter 标准接口](https://tc39.es/ecma402/#segmenter-objects)，不联网。它不做篇章理解，词界取决于浏览器实现。例如“南京市长江大桥”等名称可能被拆开；可显式加入完整个人词组。当前的算法一致性检查不等于人工确认的语言准确率。
4. **清晰度与密度独立。** 允许更强底色、六组预设和自由取色；浅深页面分别保存。需要时为标记文字配深浅字色，图片背景回退清楚的下划线。增强清晰度时不同时提高标记数量。
5. **稳定比频繁重算优先。** 保留原生高亮和未变化的范围；文本变化处理局部段落；鼠标、视频控件导致的样式变更独立合并，滚动中延后更新。真实播放帧、控件、指针与滚动加入回归检查。

## 下一步该如何判断有没有帮助

先比较原文与词组分界，固定字体和颜色；再固定分词比较密度；最后比较强度和颜色。使用难度相近的不同文章、轮换顺序，不以同一文章重读变快作证明。

主要观察：能否复述整段意思、未标信息是否漏掉、反复找行或断掉后能否接上、阅读负担、是否愿意继续。速度只是次要记录。若理解下降或干扰增加，即使更好看也要调整。

计划增加的语言评估应由不同读者标注可接受边界，并记录分歧、人名地名、简繁、跨节点与复合概念；先纠正会误导理解的边界，不用单一分词器给自身打分。持续阅读与成人中文使用者的实际收益仍未验证。

独立候选原型：轻量字距 / 行距、可退出的行位置提示、主动触发的朗读、可选段落复述。一次只验证一个作用，不打包成万能的 ADHD 模式。
