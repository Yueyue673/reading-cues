## 实测中修正的问题

- 将“即使是也门的新闻也要核实”纠正为正例，并保留只有“也门”、没有后续配对成分的反例。
- 隐藏或转为可编辑的段落会立即清除旧提示。
- 自身样式和状态文字在同一批页面变化中出现时，不再取消首次绘制；检查完成必须有实际 Range 提示。
- 编辑控件的无关样式变化不再清空正文提示。
- 扩展样式改由浏览器注入并注册，避免依赖网页允许内联样式。
- 网站脚本注册失败后恢复原站点列表，避免界面显示已启用而实际无法自动工作。
- 明确整页 2,000 组硬上限，保留成对标记的一致性。

## 自动化的限制

无界面测试不能点击浏览器原生权限弹窗。测试通过临时浏览器的扩展管理接口预授权**本机测试域名**，再由扩展实际执行 `permissions.request`、脚本注册、注入、暂停和撤回。没有改动分发用 manifest 的权限，也没有给日常浏览器授权。原生弹窗的允许 / 拒绝体验仍列为手工检查。

以下尚未完成：Chrome / Edge 品牌浏览器多版本验收、常见真实网站的广泛兼容验证、屏幕阅读器实测、中文目标使用者持续试用、随机化或临床效果验证。Firefox / Safari / 手机不在本轮支持范围。

## 安装后的手工检查

1. 在 Chrome / Edge 加载解压目录；核对原生权限弹窗只涉及当前网站，分别尝试拒绝和允许。
2. 选中短语，通过实际右键菜单添加，刷新后检查；再忽略和移除。
3. 在自己的常用文章页检查深色、缩放、复制、页面交互和关闭提示。
4. 连续数日按 [TRYOUT.md](TRYOUT.md) 记录理解、负担和漏读。若干扰变多，减少提示或暂停。
