# v0.2.0 验证记录

日期：2026-10-20（Asia/Shanghai）。本地环境：Windows、Node.js 22.23.2、Playwright 1.62.1、Chromium 145.0.7632.6，独立临时浏览器配置。

**1,028 项语言、覆盖、迁移和后台检查通过；15 组真实浏览器检查通过。** GitHub CI 会在独立 Linux 环境安装匹配的 Chromium，再运行同一套检查并保存结果与截图。此记录说明工程行为，不说明临床或阅读辅助效果。

## 全局自动的直接检查

测试加载分发用的实际 manifest 后，直接打开 `127.0.0.1` 与 `localhost` 两个不同站点：没有打开插件弹窗或设置页，没有写入启用名单，没有操作权限请求或开启按钮，两处正文都自动获得提示。

后续检查：刷新自动生效；暂停一个站点不影响另一个；全局暂停立即清除并统一恢复；跨域普通 HTTP iframe 自动工作；暂停顶层站点时其中的 iframe 也停止，独立打开的其他站点继续工作。

安装使用的是临时测试浏览器的解压加载方式，不会出现日常浏览器的原生安装弹窗。因此原生安装 / 升级权限确认仍属于手工验收，不能声称已自动测试其点击体验。

## 词库与独立语段

374 条规则包括：341 条字面词条、568 种词形；20 条配对规则、32 种配对形式；13 条上下文 / 数值模式。每条有原创正反例。逐条检查之外，用另一份原创语段集检验实际竞争后的完整表达：办事说明、天气新闻、价格变化、预约时间、项目安排、科普解释、产品条款、研究解读、技术文档、阅读建议、条件让步、繁体说明、数值范围、普通叙述和说明边界。

这 15 个有线索的新增场景中，v0.1 词库在 5 个场景产生提示，v0.2 在 15 个产生提示。另有不含适用线索的普通叙述对照，保持无提示。

**这是一份面向新增场景的原创回归集，不是随机抽样网页、真实网页覆盖率或理解效果估计。** 更多提示不代表更好理解。已知问题仍需要实际使用反馈。
