# v0.3.0 验证记录

日期：2026-10-20（Asia/Shanghai）。Windows、Node.js 22.23.2、Playwright 1.62.1、Chromium 145.0.7632.6；独立临时浏览器配置。

**1,035 项核心 / 语言 / 后台检查与 20 组真实浏览器回归通过。** GitHub CI 在独立 Linux 环境运行同一套检查并保存截图和结果。这里验证工程行为，不证明中文成人 ADHD / 阅读障碍辅助效果。

## 闪烁和性能的重现检查

旧版的相关路径：普通 `class` / `style` 属性变化会立即删除全部高亮，再安排整页扫描。网页滚动、悬停和播放器更新可能反复触发它。

新版保留相同 Highlight 对象和未变 Range。文本和样式变化分队列，样式采用尾随合并，滚动中延后处理。小段新增只处理新增文本块；删除与编辑剔除失效范围。

| 回归场景 | 验证结果 |
| --- | --- |
| 75 个连续帧改变正文容器样式、页面 class 并触发滚动 | 无整页标记清空，滚动中没有扫描增长；停止后更新，原范围对象保留 |
| 实际视频播放、进度 / 计时 / 提示控件连续更新，同时移动鼠标触发页面 class 变化 | 确认视频解码帧实际推进；未出现无标记帧；期间扫描次数未增加；多张正文截图的像素哈希一致 |
| 180 段文章后增加一段 | 新一次处理少于 100 个字符；已有段落范围对象保持，未整页重算 |
| 修改已有文字节点的开头 | 新标记与当前文字匹配，没有空范围、过期或重复标记 |
| 2,400 段合成长文 | 触及 6,000 组上限，分批让出执行；本机记录见测试输出，不作为所有设备的性能保证 |

视频源是本机 canvas 产生的实际媒体流；没有访问真实用户的播放器或抓取网络视频。测试浏览器没有覆盖日常显卡、硬件加速、所有第三方播放器和网站；不能保证所有环境的合成层问题均已排除。

## 分词、颜色与升级

- 默认 `words` 模式；普通叙述即使没有逻辑连接词也产生边界提示。检查 UTF-16 偏移、完整个人词组、忽略和三种模式。
- 默认避免零碎单字标记；浏览器分词 + 连续表达边界合并；个人词组可纠正名称拆分。缺少 `Intl.Segmenter` 时只保留显式个人词，弹窗提供说明。
- 分词检查部分验证与浏览器词界一致，**不是人工语言准确率**。人工多读者边界标注、歧义评估与长期体验尚未完成。
- 六组预设、自由取色、强度保存与刷新恢复；严格 CSP 页面确认实际渲染自定义颜色 / 透明度。
- 强底色下的浅 / 深背景样例确认文字对比度至少 4.5；不宣称对任意复杂背景都达到认证标准。
- 全新安装在两个不同站点、未打开插件 UI 前自动生效；普通跨域 HTTP iframe 自动生效并继承顶层暂停。
- v0.1 / v0.2 迁移保留个人词、忽略、样式、全局暂停、站点暂停；新默认为词组分界，没有新增权限。
- 全局暂停、单站暂停、恢复、销毁、并发写入、消息来源与导入校验保持通过。

## 保留的逻辑规则回归

374 条原创规则的正反例、完整配对、日期时间、变化量 / 结果值、词语嵌套、句界与预算继续检查。原有 15 个含线索原创语段和普通叙述对照仍保留，专门检查可选逻辑模式。

此前 v0.1 在 5 / 15、新词库在 15 / 15 语段产生提示，只是原创场景回归结果，不能称真实网页覆盖率或理解提升。v0.3 不再用该指标来解释默认词组模式。

## 页面保持与尚待验证

继续检查正文文字、HTML、节点、选区与布局高度；跨行内节点；编辑区、代码、链接、作者已有强调与动态通知排除；隐藏 / 可编辑切换；离线试读明亮 / 深色 / 窄屏和纯文字粘贴。

原生安装 / 升级界面、Chrome / Edge 多版本、实际网站、辅助技术与持续阅读仍需手工验证。PDF、图片文字、Shadow DOM 和浏览器保护页面未支持。阅读效果的比较方法见 [TRYOUT](TRYOUT.md)，研究与反面证据见 [复核](RESEARCH-REVIEW-0.3.md)。
