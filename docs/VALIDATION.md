# v0.6.1 验证记录

日期：2026-10-20（Asia/Shanghai）。本地 Windows、Node.js 22.23.2、Playwright 1.62.1、Chromium 145.0.7632.6，独立临时浏览器配置。

**1,050 项核心 / 语言 / 后台检查与 30 组浏览器回归。** GitHub CI 在独立 Linux 环境运行相同检查，保存结果和截图。以下验证工程行为，不证明阅读辅助效果。

## 工作台与可选辅助

工作台检查粘贴窗口的空内容、Esc 关闭、素材前后导航、选区预览、键盘添加与撤销、完成后的双栏对照、自动与人工范围分离、继续修改，以及浅色 / 深色 / 窄窗口。

新安装默认背景 / 多色 / 强度 20%，阅读尺和段落聚焦默认关闭。辅助开启后有可见横带或四边遮罩，原文 HTML 保持，点击可穿透；编辑区不显示。连续指针移动后正文扫描次数不增加。实际扩展在严格 CSP 下也能绘制，暂停会删除辅助层，恢复关闭状态后无残留。

文档中的功能案例来自真实构建，`scripts/capture-preview.mjs` 可重新生成。`docs/assets/cover.png` 是同一份原创通知的开启前后截图：在独立临时浏览器安装实际扩展，先取默认自动标记，再暂停取原文，两次正文 HTML 和布局高度一致。图片只做排版，不另画标记。

个人词库案例通过实际设置表单添加“截止时间”，在“只提示个人词库”模式确认两个范围都与这个词完全一致。阅读尺和段落聚焦使用同一通知、同一鼠标位置；开启后正文 HTML 和布局高度不变。另检查设置页深色显示、390px 窄窗口和工作台窄窗口，无横向溢出。原始截图及核对结果在忽略的 `artifacts/doc-captures/`。

本版修改说明文字、界面标签和案例展示，没有调整选词规则。下面的语言与兼容性回归继续适用。

宣传素材更新后，README 的横向封面和四张海报使用模型生成的概念插画，并明确标注；实际标记和设置仍用扩展截图。`scripts/make-posters.mjs` 再次核对同一短句的原文与布局保留、个人词语两个精确范围、段落聚焦运行、四张 2160 × 2700 图片的尺寸与底部间距，以及最终整张海报二维码的实际解码。另人工查看原图和 360 × 450 手机尺寸图。生成提示词与已选素材记录在[视觉说明](ART-DIRECTION.md)，不把概念画面当作功能证据。

## 标注与结构候选

v0.5 新增的否定、数值与日期边界检查，以及标注编辑 / 撤销 / 导出 / 草稿 / 确认空标注的具体场景见 [本轮迭代](ITERATION-0.5.md)。实际浏览器验证了重复词位置、JSON 下载、切换后保留、刷新后清除、三档密度和窄屏操作条。

三段原创文字由使用者标出 31 个片段。严格起止边界一致：旧逐词方案 4 个，新候选轻量档 15 个、均衡档 24 个、较多档 27 个。**这些材料参与过规则调整，不是独立准确率。** 生成数量和校准过程见 [ANNOTATION-DESIGN](ANNOTATION-DESIGN.md)。

构式回归另外检查：新的时间动作、变化谓语、修饰语＋名词；否定不被剥离；不以悬空修饰或量词结束；标点和 UTF-16 偏移；忽略；字面个人词组与长词。新题材段落没有使用者标注，不制造“正确答案”分数。

`compare.html` 确认可以切换原文、旧分词、新候选与原始标注，同一段文字保持；纯文字粘贴与未标注新段落的状态正确。它是差异观察工具，不是临床测试或自动评判最佳方案的工具。

## 开放评论组件

以下本地浏览器场景在 v0.5 继续回归；下述真实 B 站页面计数来自 v0.4 的历史检查，本轮没有扩大真实网站覆盖。

| 场景 | 检查 |
| --- | --- |
| 仿 B 站多层开放影子树 | 正文有实际像素变化，原 HTML、文字与编辑区保留 |
| 动态楼中楼、隐藏与可编辑切换 | 新回复自动处理，隐藏 / 编辑内容不标 |
| 初始存在的自定义组件晚些调用 attachShadow | 针对已发现的宿主检测，不定时整页重扫 |
| 关闭的影子树 | 不读取、不注入样式 |
| 移除、暂停、销毁 | 清理失效范围、观察与本插件拥有的样式表 |
| 实际 MV3 扩展＋严格网页 CSP | 开放树中的样式与自定义底色实际生效 |

另在一个公开页面 `https://www.bilibili.com/video/BV1GJ411x7h7/` 使用实际分发扩展检查。只读访问，暂停视频，无账号登录或评论操作。该次记录发现 17 个参与处理的开放树，评论 / 楼中楼富文本中 22 个范围获得下划线；评论输入区为 0。切换稳定多色＋加重下划线后，6 个颜色系列生效，输入区仍为 0。

该记录不保存评论文字或用户信息。它只代表一次页面实测，不能推广为所有 B 站状态和全部网站已兼容。

## 显示与稳定性

- 稳定多色在重扫后分配不变；相同词组使用相同颜色，换种子才改变分配。默认最浅的稳定多色，密度与颜色独立。
- 描边式加重的实际截图像素改变，HTML、节点与布局高度不变；加重＋下划线组合生效。它不是修改字体字重。
- 强底色的浅 / 深背景样例文字对比度至少 4.5；多色下划线使用亮暗配色与对比不足回退。不能覆盖所有图片和混合背景。
- 75 个连续帧修改样式并滚动：无清空标记帧，滚动期间扫描次数不增长，停止后保留原范围对象。
- 实际 canvas 媒体流播放、播放器控件更新与指针移动：视频帧推进、正文截图哈希一致、无标记清空、扫描次数不增长。
- 180 段文章增加一段：只处理少于 100 个字符，原段落范围对象保留。修改文字节点后没有过期或空范围。
- 2,400 段合成长文遵守 6,000 组上限；词性初始化和扫描分批让出执行。测试门槛不作为所有设备的性能保证。

## 安装、权限与既有功能

全新安装在两个不同站点、没有打开插件 UI 前自动生效；默认意义块 / 稳定多色 / 底色 20%。普通跨域 HTTP iframe 自动生效，并继承顶层网站暂停。

升级保留个人词、忽略、显式暂停、站点列表和已保存样式；原逐词模式迁移到新候选，可切回。没有新增权限。并发写入、消息来源、导入校验、单站 / 全局暂停与恢复继续检查。

374 条原创规则的正反例、配对、数值、句界与预算继续作为可选逻辑模式回归。正文 HTML、文字、选区与布局保留；代码、链接、作者强调、动态通知排除；离线明亮 / 深色 / 窄屏、原文模式、纯文字粘贴继续通过。

原生安装 / 升级界面、多浏览器版本、更多实际网站、辅助技术与长期阅读仍待手工验证。当前不支持关闭的影子树、PDF、图片文字和浏览器保护页。
