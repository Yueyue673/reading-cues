# 小步改进路线

## v0.3.0：当前已实现

- 根据明确偏好，默认本地词组分界；逻辑提示与仅个人词可选。个人词组纠正与忽略覆盖全部模式。
- 保留原生 Highlight 与未变 Range；小段增量处理；样式独立尾随合并，滚动中延后。
- 真实视频帧、鼠标移动、播放器控件更新、滚动和正文截图一致性回归。
- 六组预设、浅深页面自由取色、20–85% 强度与文字对比保护。
- [语言学 / 心理学复核](RESEARCH-REVIEW-0.3.md) 记录相反证据与待验证假设。

## v0.2.0：历史版本

- 374 条原创规则、568 种字面词形、32 种配对形式、13 条上下文 / 数值模式；九类默认覆盖；完整配对。
- 两种不改变文字布局的样式；亮暗背景；有限对比度回退。
- 个人词语、忽略、右键添加、JSON 备份。
- 默认全局自动，无需逐站启用；按需暂停一个网站或全部；普通 HTTP / HTTPS 嵌入页同步处理。
- 自动段落数量、动态合并扫描、保留有效提示与硬上限；原文和编辑区保护。
- 离线试读页；自动检查；MIT；隐私与研究边界。

## 下一轮：由真实反馈选择

优先级依次是：误导性误标、正文 / 编辑兼容问题、阅读负担、稳定性，再考虑扩大词库。每条改动先有可重现例句和失败检查，再修正，再复核实际页面。尽可能一次改变一件事。

候选方向：先由多位读者标注可接受词界与歧义，特别检查人名、地名、复合概念和简繁混排；实际比较理解、负担与未标内容遗漏。在明确授权的网站中扩大兼容性测试。词条数量与标记数量不作效益指标，不推断用户困难词。

## 独立原型，暂不并入

字距 / 行距、阅读位置提示、段落聚焦、朗读、主动段落复述和解释。每个都应拥有单独的开关、退出方式、兼容与体验验证，避免主插件不断增加操作负担。

没有创建无人值守的持续发布或自动收集反馈任务。每次迭代的测试结果与使用者效果分别记录。
