# 小步改进路线

## v0.6.0：当前已实现

工作台的素材、正文和标注操作分开；标完直接对照。默认显示改为 20% 强度的稳定多色底色。阅读尺、段落聚焦以独立可选辅助提供，默认关闭。

## 更多辅助方向

| 方向 | 当前状态 | 想解决的困难 | 下次需要检查 |
| --- | --- | --- | --- |
| 阅读尺 | 已提供，可选 | 看丢当前行 | 横带是否反而挡字、是否需要调整高度 |
| 段落聚焦 | 已提供，可选 | 周围内容太多 | 是否容易忽略段外信息，控件是否仍可操作 |
| 朗读当前段 | 候选 | 只看文字容易卡住 | 本地中文语音、朗读控制、信息是否外传 |
| 恢复阅读位置 | 候选 | 中断后找不到进度 | 主动保存的位置、页面改版后的定位、隐私 |
| 字号与行距 | 候选 | 字太密或行距不合适 | 中文排版、窄窗口和作者原布局 |
| 临时任务提示 | 候选 | 打开新页后忘了原来要做什么 | 用户主动写一句目标，何时出现才不打断 |

这些方向不是诊断或治疗方案。W3C 的认知无障碍补充指导建议减少干扰、让操作路径更短，并允许个性化；据此选择可控的小功能，不代表它们已对 ADHD 人群验证有效。[帮助用户保持任务焦点](https://www.w3.org/WAI/WCAG2/supplemental/objectives/o5-user-focus/)

留白和布局可以尝试调整，但不应大到让重要内容移出首屏。[W3C：使用留白](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o3p10-whitespace/) 朗读和文字呈现是可以提供的替代方式，仍需要按个人偏好控制。[W3C：内容呈现](https://www.w3.org/WAI/people-use-web/tools-techniques/presentation/)

每次先试一个辅助，再记录是否更容易读完整段、理解是否保持、未强调信息是否被漏掉。暂不加入自动计时、打卡、积分或行为推断。

## v0.5.0：历史版本

- 修正附着否定、数值单位、变化与结果、日期时刻及短否定分句候选。
- 对照页直接标注，精确位置、重复词、撤销、草稿 / 确认、主动复制与导出；可切换三档密度。
- 新增三段边界检查文字，明确属于开发检查，不作为盲测或个人效果证据。
- [问题、研究复核与实现边界](ITERATION-0.5.md)。下一轮继续使用新的个人反馈；先确认边界是否合适，再检验理解和负担。

## v0.4.0：历史版本

- 三段 / 31 个标注驱动的结构候选与三档密度；标注、算法和新题材的离线对照页。
- 下划线默认；描边式加重与组合；稳定可选多色、主动换种子。
- 嵌套开放评论树、动态回复、延迟组件、样式和清理；一个公开 B 站页面实际扩展验证。
- 内置 MIT 词性精简数据，初始化分批让出执行；不将校准拟合当作阅读效果。

下一步先收集新段落的使用者标注，记录遗漏、额外片段、别扭边界与整段理解；观察参数是否在新题材仍适用，再决定扩大结构或调整默认。不继续用已经见过的三段声称找到最佳算法。

## v0.3.0：历史版本

- 根据明确偏好，默认本地词组分界；逻辑提示与仅个人词可选。个人词组纠正与忽略覆盖全部模式。
- 保留原生 Highlight 与未变 Range；小段增量处理；样式独立尾随合并，滚动中延后。
- 真实视频帧、鼠标移动、播放器控件更新、滚动和正文截图一致性回归。
- 六组预设、浅深页面自由取色、20–85% 强度与文字对比保护。
- [语言学 / 心理学复核](RESEARCH-REVIEW-0.3.md) 记录相反证据与待验证假设。

## v0.2.0：历史版本

- 374 条原创规则、568 种字面词形、32 种配对形式、13 条上下文 / 数值模式；九类默认覆盖；完整配对。
- 两种不改变文字布局的样式；亮暗背景；有限对比度回退。
- 个人词语、忽略、右键添加、JSON 备份。
- 默认全局自动，无需逐站启用；按需暂停一个网站或全部；普通 HTTP / HTTPS 嵌入页同步处理。
- 自动段落数量、动态合并扫描、保留有效提示与硬上限；原文和编辑区保护。
- 离线试读页；自动检查；MIT；隐私与研究边界。

## 下一轮：由真实反馈选择

优先级依次是：误导性误标、正文 / 编辑兼容问题、阅读负担、稳定性，再考虑扩大词库。每条改动先有可重现例句和失败检查，再修正，再复核实际页面。尽可能一次改变一件事。

候选方向：先由多位读者标注可接受词界与歧义，特别检查人名、地名、复合概念和简繁混排；实际比较理解、负担与未标内容遗漏。在明确授权的网站中扩大兼容性测试。词条数量与标记数量不作效益指标，不推断用户困难词。

## 独立原型，暂不并入

字距 / 行距、阅读位置提示、段落聚焦、朗读、主动段落复述和解释。每个都应拥有单独的开关、退出方式、兼容与体验验证，避免主插件不断增加操作负担。

没有创建无人值守的持续发布或自动收集反馈任务。每次迭代的测试结果与使用者效果分别记录。
